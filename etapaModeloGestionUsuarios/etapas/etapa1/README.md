# Etapa 1 — Análisis de requerimientos y funcionalidades

> Corresponde a `etapasdetrabajo.md` Etapa 1.

## Objetivo
Definir **qué debe hacer el sistema** antes de programar.

## Actividades
- Descripción general del sistema y problema a resolver (entrevistas a actores).
- Detalle de funcionalidades.
- **Bocetos de interfaces** (qué elementos HTML tiene cada página).
- Explicación de cada boceto.
- Navegación entre páginas/secciones.
- Información a almacenar (pre-base de datos).

## Entregable
`etapa1.zip` con documento + bocetos (imagen/pdf/foto) + validación con destinatarios.

## En este proyecto
La Etapa 1 original es `etapa1/` en la raíz del repo (formulario simple sin BD).
En esta carpeta `etapas/etapa1/` se deja constancia documental del análisis.

### Ejemplo de requerimientos relevados
- Formularios de personas y ciudades con ABM.
- Gestión de usuarios con login y roles.
- Navegación: portada → login → home/dashboard → módulos según rol.

### Bocetos (referencia)
- Portada con `image.png` y `cartel.png` + formulario login (usuario, clave, ingresar, olvidé mi clave).
- Dashboard con cards de estadísticas y accesos.
- Tablas con buscador y botones Modificar/Eliminar.
- Formularios de alta/edición con validación y select de FK.

Ver `../../etapa1/` para la implementación mínima sin BD del proyecto base.
