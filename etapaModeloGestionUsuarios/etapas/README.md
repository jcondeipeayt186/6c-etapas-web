# Etapas del proyecto (histórico)

Este directorio conserva la traza de las etapas previas según `etapasdetrabajo.md`.

- `etapa1/` — Análisis y bocetos (formulario sin BD).
- `etapa2/` — Diseño de BD (DER/MER).

- `etapa4/` — Diseño interfaz Bootstrap.

La **Etapa 5** es la aplicación final que vive en la raíz de `etapaModeloGestionUsuarios/` (ver `../README.md`).
